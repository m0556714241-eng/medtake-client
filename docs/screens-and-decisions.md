# תכנון פרויקט React – MedTake, מעקב נטילת תרופות (מטפל / מטופל)

## עקרונות
- שני תפקידים בלבד: **מטפל** (caregiver) מנהל, **מטופל** (patient) צופה ומסמן "לקחתי".
- כל מי שנרשם הוא מטפל. מטפל יוצר חשבונות למטופלים שלו (מייל + סיסמה). אין קוד הזמנה.
- למטפל כמה מטופלים, למטופל מטפל אחד בלבד. אין ניהול עצמי.
- רק המטופל מסמן נטילה. המטפל צופה בלבד.
- לפי הנחיות המורה: את קוד ה־React כותבת התלמידה בעצמה. AI מסייע בתכנון, בהסברים, בבדיקת קוד ובשרת.

## מסכים וקומפוננטות

### 1. עמוד כניסה – `Entrance` (עמוד)
- `Login` – מייל + סיסמה → מעבר לעמוד הראשי לפי תפקיד.
- `Register` – הרשמה כמטפל (שם, מייל, סיסמה) → מעבר לעמוד הניהול.

### 2. Header (קומפוננטה, בכל העמודים)
- לוגו – תמיד, לחיצה מחזירה לעמוד הראשי.
- שם המשתמש + Logout – רק אחרי התחברות.
- "ניהול" – רק למטפל → `Manager`.
- "התרופות שלי" – רק למטופל → `MyMedicines`.
- ניווט עם `NavLink`, העמוד הפעיל מודגש.

### 3. עמוד ניהול – `Manager` (עמוד, מטפל)
- כרטיס לכל מטופל: עיגול עם האות הראשונה של השם, שם, גיל (מחושב מ־birthDate), תאריך הצטרפות.
- סיכום פיקוח בכרטיס (שדות מחושבים בשרת): נלקחו היום X/Y, צבע, סמל מלאי נמוך.
- עריכה (פותח `AddPatient` עם ID) ומחיקה (עם אישור לפני מחיקה).
- לחיצה על הכרטיס → עמוד מטופל בודד.
- כפתור Add → `AddPatient`.
- `FiltersPatient`: חיפוש לפי שם, מיון לפי שם / תאריך הצטרפות, סינון: מלאי נמוך, פוספס היום.
- מצב ריק: הודעה "עדיין אין מטופלים", וטופס ההוספה נפתח אוטומטית כחלון קופץ (Skip סוגר).

### 4. `AddPatient` (קומפוננטה, חלון קופץ)
- שדות: שם, מייל, סיסמה, תאריך לידה.
- הוספה ועריכה באותה קומפוננטה: מקבלת ID של מטופל → מצב עריכה. בעריכה סיסמה ריקה = ללא שינוי.

### 5. עמוד מטופל בודד (עמוד, מטפל)
- פרופיל: שם, תאריך הצטרפות, גיל, כמה תרופות נוטל.
- פירוט היום: שימוש חוזר ב־`DailyMedicine` עם ID המטופל, בלי אפשרות סימון.
- רשימת מרשמים ככרטיסים: שם, מינון, צורה, ימים ושעות, מלאי (+ סמל מלאי נמוך), סטטוס.
- פעולות בכרטיס: עריכה (`AddMedicine`), חידוש מלאי (`RefillStock`), סיום/השהיה דרך סטטוס, מחיקה רק למרשם שנוצר בטעות.
- כפתור Add → `AddMedicine`.
- פילטרים ומיון: חיפוש לפי שם תרופה, סטטוס, צורה, מיון לפי שם / מלאי.

### 6. `AddMedicine` (קומפוננטה, חלון קופץ)
- טופס אחד להוספה ועריכה לפי ID.
- לוח זמנים: בחירת ימים בשבוע + רשימת שעות קבועות.

### 7. `RefillStock` (קומפוננטה, חלון קופץ)
- "כמה יחידות להוסיף?" → השרת מוסיף למלאי הקיים.

### 8. עמוד התרופות שלי – `MyMedicines` (עמוד, מטופל)
- ברירת מחדל: תצוגה יומית של היום. מתג יומי / שבועי.
- `DailyMedicine`: יום ותאריך, רשימת מנות (שם, מינון, שעה, סטטוס), סימון / ביטול סימון "נלקח", סמל מלאי נמוך, סרגל "נלקחו X מתוך Y".
- `WeeklyMedicine`: השבוע הנוכחי, כרטיס לכל יום (יום, תאריך, סיכום X/Y, צבע). לחיצה → פירוט יומי של אותו יום.

## כללי לוגיקה
- סימון "נלקח" מוריד מהמלאי `unitsPerDose` (עד 0), ביטול מחזיר בדיוק את מה שירד.
- אפשר לסמן מנה שפוספסה (השלמה) ומנה עתידית.
- מנות אינן נשמרות מראש: השרת מחשב אותן מלוח הזמנים לטווח תאריכים, ושומר רשומה רק בסימון. "פוספס" מחושב לפי `missedAfterMinutes`.
- מלאי נמוך (`stockQuantity <= lowStockThreshold`): התראה בתוך האפליקציה למטפל ולמטופל.

## החלטות שנסגרו בהמשך
- טיפוסים: נוספו `PatientSummary`, `CreatePatientRequest`, `UpdatePatientRequest`, `PatientFilters`, `Dose`, `DaySummary`, `DoseFilters`, `MarkIntakeRequest`, `RefillRequest`, `LowStockAlert`; `patientId` נוסף לפילטרים. `role` נשאר ב־`RegisterRequest` (השרת מתעלם ממנו).
- שם האפליקציה: **MedTake**.
- שרת: Node + Express + Prisma (בתיקייה `medtake-server`). מסד ושרת ב־Render.
